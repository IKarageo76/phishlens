# Custom background photo (optional)

Drop a photo named `custom.jpg` in this folder to show it behind the neon theme,
blended into the scene at low opacity. Use only images you have the right to use
(your own, or a free licence such as Unsplash or Pexels). Rebuild the web image after
adding it: `docker compose up -d --build web`.

The repository ships only original artwork, so no stock photos are included.
